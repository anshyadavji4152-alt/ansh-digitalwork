# ANSH DIGITAL
Premium black-and-gold creative agency portfolio built with React + Vite, Supabase and Netlify.

See [SETUP-HI.md](./SETUP-HI.md) for Hindi deployment and Supabase setup instructions.

## Features
- Responsive luxury black + gold design
- Services, selected work, about and contact sections
- Video portfolio categories and inline player
- Supabase email/password admin login
- Upload video + optional thumbnail, list and delete portfolio entries
- WhatsApp contact CTA
- Netlify SPA redirect and build configuration
